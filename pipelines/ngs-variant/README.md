# NGS Variant Pipeline (Domain D2)

End-to-end germline short-variant workflow on public data — the pipeline
competency behind "NGS analysis" course cores (NYU 7653, GA Tech 6150/7210,
Georgetown 5990, UCSD BISB).

## Workflow

```
FASTQ (1000 Genomes subset)
  → QC            FastQC + MultiQC report
  → trim          fastp (or trimmomatic)
  → align         BWA-MEM → BAM (samtools sort/index/markdup)
  → call variants bcftools mpileup/call (GATK HaplotypeCaller optional arm)
  → filter        hard filters + VCF QC metrics
  → annotate      Ensembl VEP or snpEff → consequence table
  → report        MultiQC + summary notebook
```

## Standard

- Data: chromosome-bounded 1000 Genomes exome/WGS subset (see
  `data/MANIFEST.md` C3) — small enough for a workstation
- Orchestration: Nextflow or Snakemake (pick one, justify in README)
- Containers: workflow runs inside `env/Dockerfile` image
- Validation: genotype concordance vs published 1000G calls on the
  same samples — the "did the pipeline get the right answer" number
- Output: `results/` is regenerated by a single `nextflow run`; nothing
  hand-produced
